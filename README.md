# 💡 טיפים לסטודנטית

ברוכות הבאות למאגר המשותף של סדנת Git ו-GitHub!

כאן אוספות יחד טיפים ללימודים, שכל אחת מאיתנו למדה בדרך הקשה 😉
כל הטיפים נמצאים בקובץ **[tips.md](tips.md)**.

---

## ✍️ איך מוסיפים טיפ

1. נכנסות לקובץ **tips.md**
2. לוחצות על **העיפרון** ✏️ בפינה הימנית העליונה של הקובץ
3. יורדות לסוף הקובץ ומוסיפות **שורה אחת**, במבנה הזה:

```
- הטיפ שלי – השם שלי
```

4. לוחצות על הכפתור הירוק **Commit changes**
5. בחלון שנפתח כותבות הודעה קצרה, למשל: `Add Sara's tip`
6. לוחצות שוב **Commit changes** – וזהו! הטיפ שלך נשמר 🎉

> 💬 קיבלת הודעה שהקובץ השתנה בזמן שערכת?
> זה קורה כשכמה בנות עורכות את אותו קובץ באותו רגע. זו **התנגשות** (conflict) – בדיוק מה שדיברנו עליו בסדנה. מעתיקות את השורה שלך, מרעננות את הדף ומנסות שוב.

---

## 📝 מה זה קובץ md?

**md** הוא קיצור של **Markdown**.
זה קובץ טקסט רגיל, עם כמה סימנים פשוטים שהופכים אותו למעוצב.
GitHub מציג אותו יפה ישר באתר – כמו הקובץ שאת קוראת עכשיו!

כל קובץ README במאגר הוא קובץ md. כשתבני פרויקטים לתיק העבודות, תכתבי להם README בדיוק ככה.

## 🔤 התחביר הבסיסי

| מה כותבים | מה רואים |
|---|---|
| `# כותרת גדולה` | כותרת ראשית |
| `## כותרת משנה` | כותרת קטנה יותר |
| `**טקסט**` | **טקסט מודגש** |
| `*טקסט*` | *טקסט נטוי* |
| `- פריט` | נקודה ברשימה |
| `1. פריט` | רשימה ממוספרת |
| `[טקסט](https://github.com)` | [קישור](https://github.com) |
| `` `קוד` `` | `קוד` |
| `> ציטוט` | פסקה מוזחת, לציטוט או הערה |
| `---` | קו מפריד |

### כמה דברים שכדאי לדעת

- **שורה ריקה** בין פסקאות – בלי שורה ריקה, שתי שורות מתחברות לפסקה אחת
- **רווח** אחרי הסימן: `# כותרת` עובד, `#כותרת` לא
- **אימוג'י** עובדים רגיל 😊
- **קטע קוד ארוך** – שמים שלוש גרשיים הפוכות (\`\`\`) בשורה לפניו ובשורה אחריו:

````
```
git add .
git commit -m "my message"
git push
```
````
